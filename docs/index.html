PORTFOLIO / 定期実行の自動化

公開データを毎日取得して蓄積するデモ

GitHub Actions で毎朝 06:10 JST に無人実行し、取得結果と品質を記録しています。 このページも自動更新されます。

蓄積データ

日付天気最高最低取得時刻
欠損を隠していません。 最低気温は予報に含まれない日があり、その場合は空欄のままにしています。 見た目を整えるために 0 や前日値で埋めると、 「エラーは出ていないのに数字が合わない」という最も気づきにくい不具合になります。

この仕組みが備えていること

決まった時刻に無人実行PCを開いていなくても動きます
構造の変化を検出したら停止取得元の仕様が変わったら、続行せず異常終了します
失敗したらIssueで通知見に行かないと気づけない状態にしません
品質を数値で記録必須項目の充足率を毎回出力します
取得元と時刻を全件に保持あとから監査できます
取得元：気象庁の公開データ（認証不要）／ 品質レポート
